# ECOS 핵심 지표 수집 검증 기록

## 검증 범위

- 수집 대상: 한국은행 ECOS 월별 기준금리(`722Y001`)와 가계대출 연체율(1일 이상, `901Y054`)
- 검증 기간: 2020-01 ~ 2024-12
- 결과: 기준금리 60건 + 가계대출 연체율 60건 = **120건**
- 수집 모듈: `backend/app/services/ecos.py`
- 저장 모듈: `backend/scripts/import_ecos.py`
- 재실행 정책: Firestore의 `날짜 + indicator` 조합을 먼저 확인하고, 이미 있는 관측값은 건너뛴다.

## 보안 원칙

ECOS API 키는 별도 `.env`에서 실행 프로세스 환경 변수로만 읽었다. 키 값은 저장소·노트북·로그·문서에 기록하지 않았으며, 수집 후 환경 변수에서 제거했다.

## 해석 범위

두 지표는 월별 공개 집계 통계다. 기준금리는 상환 부담 환경의 후보 신호이고, 가계대출 연체율은 조세 체납의 직접 통계가 아닌 대리 지표다. 따라서 개인의 체납 상태, 압류 가능성, 세무·법률 판단을 결론으로 내리지 않는다.
