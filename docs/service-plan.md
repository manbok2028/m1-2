# 체납리셋 Signal AI 서비스 기획서

## 1. 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 체납리셋 Signal AI |
| 대상 | 체납 문제를 이해하려는 시민·소상공인, 상담 준비자 |
| 목적 | 공개 거시경제 지표의 추세와 한계를 이해하기 쉽게 요약한다. |
| 비목적 | 개인 체납 판단, 압류 가능성·세금·법률 자문, 납부 능력 예측 |

## 2. 데이터 전략

핵심 분석은 월별로 충분히 축적되는 공개 시계열을 우선한다. 기준금리와 가계대출 연체율은 ECOS에서 검증한 핵심 두 지표로 사용한다. CPI·자영업 폐업률·개인회생·지방세 체납 등은 데이터 출처, 단위, 발표 주기와 결측을 확인한 뒤 별도 지표로 추가한다.

| 지표 | 주기 | 용도 | 한계 |
| --- | --- | --- | --- |
| 기준금리 | 월 | 상환 부담 환경의 선행 후보 | 체납의 직접 원인이 아님 |
| 가계대출 연체율 | 월 | 체납 위험의 대리 신호 | 조세 체납 통계가 아님 |
| 국세 체납액 | 주로 연 | 장기 맥락·검증 후보 | 월별 시차분석에는 관측 수가 부족 |

`data`의 관측값은 `date, indicator, value, unit, source, memo`로 저장한다. 최소 100개 조건은 월별 기준금리 60건 + 가계대출 연체율 60건으로 충족하며, 실제 ECOS 수집은 기본 2015-01~2024-12의 240건이다.

## 3. 화면 구성

1. **AI 채팅**: 질문, 로딩, 요약 근거 답변, 한계 고지
2. **지표 관리**: 월별 관측값 CRUD, 출처 기록, CSV 내보내기
3. **대화 기록**: 자동 저장 목록과 전체 messages 재표시
4. **요약·그래프**: 기간·통계·추세와 가계대출 연체율 추세선

## 4. AI 컨텍스트 설계

입력은 자연어 질문이고, 서버는 Firestore에서 지표별 기간·건수·평균·최대·최소·최신값·최근 변화율을 계산한다. 이 요약과 “집계 지표이며 개인 판단 금지” 문구를 시스템 프롬프트에 넣은 뒤 GPT를 호출한다. 답변은 대화 기록에 자동 저장된다.

## 5. 실패 처리와 안전장치

| 상황 | 처리 |
| --- | --- |
| 질문 누락·형식 오류 | Pydantic 422 및 브라우저 필수값 검증 |
| 지표 데이터 없음 | 먼저 관측값을 추가하라는 400 안내 |
| OpenAI 오류·키 누락 | 502/503과 재시도 안내 |
| Render 콜드스타트 | 채팅 로딩 문구 표시 |
| 개인 정보 입력 | 서비스 목적상 저장하지 않으며 공개 집계지표만 사용 |
